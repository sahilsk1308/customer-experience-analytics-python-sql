# Customer Experience Analytics Using Python and SQL

## Project Overview
This beginner-level data analytics project explores 5,000 synthetic customer survey records to understand customer satisfaction, Net Promoter Score (NPS), and customer experience trends.

The objective is to demonstrate how Python and SQL can be used to analyse customer feedback, identify patterns, and communicate findings.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- SQLite
- Google Colab

## Key Analyses
- Data quality checks and validation
- NPS segmentation: Promoters, Passives, and Detractors
- NPS analysis by contact reason
- Customer Satisfaction (CSAT) analysis
- Resolution status analysis
- Customer experience KPI summaries
- Monthly NPS trend analysis
- Regional customer experience analysis
- SQL queries for customer segmentation and performance analysis

## Dataset
The project uses 5,000 randomly generated synthetic customer survey records.

The dataset includes survey dates, regions, contact reasons, customer types, NPS ratings, CSAT scores, customer effort scores, and resolution statuses.

**Disclaimer:** The dataset is fictional and does not represent actual customer information or real business performance.

## Key Learning Outcomes
- Data manipulation and aggregation using Pandas
- Calculation of customer experience metrics
- Exploratory data analysis and visualisation
- SQL querying using SQLite
- Translating analytical results into business insights

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run the notebook cells in order.
3. Review the analysis tables, visualisations, and SQL query results.
